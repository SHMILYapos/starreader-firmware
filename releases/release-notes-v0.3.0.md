# StarReader Pro v0.3.0 - UI完善版

## 🎉 版本亮点

这是StarReader Pro固件的第三个正式版本，重点完善了系统UI体系和设置界面。

### ✨ 新功能

#### 📱 完整设置体系
- **显示设置子页** - 字号/行距/边距/刷新模式/屏幕方向/自动全刷
- **阅读设置子页** - 翻页方式/状态栏显示/进度同步/电量显示
- **前光设置子页** - 开关+亮度滑块+色温滑块+预设模式
- **网络设置子页** - WiFi开关/网络扫描/当前连接/Web传书/OTA
- **系统设置** - 关于设备页面

#### 📶 WiFi网络扫描
- 异步网络扫描功能
- 扫描进度条界面
- 网络列表显示（SSID+信号强度）
- 支持按键+触屏双操作

#### 🎨 UI组件完善
- **前光快捷面板** - 顶部下拉，实时调节亮度色温
- **应用中心 Apps Hub** - 4x2图标宫格
- **阅读器弹出菜单** - 底部弹出菜单（目录/书签/设置/夜间模式）
- **统一设计语言** - 标题栏+列表+底部提示，所有界面风格一致

#### 📚 TXT阅读器增强
- 翻页功能完善
- 状态栏自动隐藏
- 快捷前光面板
- 阅读进度自动保存

### 📦 硬件支持

## 📥 下载说明

### 固件文件
- `starreader-pro-v0.3.0.bin` - OTA升级固件包
- `starreader-pro-v0.3.0-factory.bin` - 完整工厂固件（首次烧录用）

### 烧录方法
```bash
# 首次烧录使用factory固件
python -m esptool --chip esp32c3 --port /dev/ttyUSB0 --baud 921600 write_flash 0x0 starreader-pro-v0.3.0-factory.bin
```

> ⚠️ **注意**：烧录前请务必备份原始固件！
